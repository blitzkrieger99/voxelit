## Quick start
> [!IMPORTANT]
> Requires Rust 1.85+ (the project uses edition 2024). Get it from [rust-lang.org](https://rust-lang.org/).
``` bash
git clone https://github.com/blitzkrieger99/voxelit.git
cd voxelit
cargo build
cargo run
```
